# NOTICE — provenance and third-party material

This private repository contains user-maintained code and archived TradingView/community reference scripts.

1. `archive/sources/reference/` is reference evidence, not automatically project-owned code.
2. Original author/copyright/license notices are preserved whenever they existed in the source.
3. No repository-wide open-source license is applied during reboot because that could incorrectly relicense third-party material.
4. Reuse into `src/core/` requires provenance/licensing review as well as engineering review.
5. Reimplementation is preferred over copying when provenance or maintainability is unclear.

Automatic header scan found 17 scripts with an MPL/Mozilla Public License reference and 25 with an explicit copyright/attribution marker in the first 25 lines. This is an engineering inventory, not a legal conclusion.
