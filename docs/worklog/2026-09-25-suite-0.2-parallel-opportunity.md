## 5. Semantic diagnosis

### Parallel path
**KEEP**

It guarantees exact frozen 0.1 independence and lets new opportunity classes use their own lifecycle.

### CANDIDATE -> PREPARANDO
**REMOVE / REFINE**

Reason:
- CANDIDATE is useful early information;
- but exposing every candidate through readiness creates excessive short-lived PREPARANDO churn;
- operator-facing candidate awareness belongs in the Opportunity layer (`OBSERVAR`), not necessarily Execution readiness.

### STRONG / ACCEPTED composition
**REFINE**

The first machine still reused the pullback-specific simultaneous confirmation burden too literally.

For breakout/reacceleration:
- structural follow-through itself is new evidence;
- a strong source bar may already have carried valid PSE participation;
- requiring fresh MTE acceleration + fresh PSE confirmation again after two held closes can reject a move merely because momentum has progressed from acceleration into normal deceleration.

This does not justify changing MTE/RSE/PSE state definitions.

It justifies opportunity-specific **composition and evidence memory**.
