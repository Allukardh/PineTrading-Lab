## 1. What was tested

- frozen Market Map 0.1;

## 4. Preservation finding

The counterfactual did **not** reduce pullback/retest coverage.

However, prior opportunity-derived state persisted into some later frozen relevant-location bars:
- 4H relevant-state divergence: **2.15%**
- 1D relevant-state divergence: **2.70%**

That violates the intended architectural cleanliness of "preserve 0.1 path; add new opportunity paths" even if aggregate pullback coverage improved.

## 5. Decision

### Old-location projection via `APPROACHING`
**REFINE / DO NOT PROMOTE**

Reason:
- it proves broader opportunity context can reach the accepted Execution components;
- but it mixes unrelated semantic domains;
- it adds churn;
- it can contaminate the frozen pullback/retest state path;
- daily breakout timing can become later rather than earlier;
- it does not sufficiently separate held from fakeout in 1D.

### Opportunity object
**KEEP**

The explicit:
- kind;
- stage;
- direction;
- source;
- acceptance lifecycle

is the correct abstraction.

### Accepted component semantics
**KEEP**

No evidence justifies changing:
- MTE;
- RSE;
- PSE;
- frozen 0.1 pullback/retest state path.
