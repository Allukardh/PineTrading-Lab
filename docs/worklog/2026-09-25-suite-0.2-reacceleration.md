## 1. Why the first contract changed

The first REACCELERATION draft used a fixed 24-bar "recent pullback" veto.

That produced only:
- BTC 4H: 29 episodes
- BTC 1D: 2 episodes

Context instrumentation showed the fixed window was conflating elapsed time with market sequence.

The contract was therefore changed **before product interpretation** to a structural-sequence rule:

- there must be an established coherent regime;
- there must be a prior same-direction structural break;
- if a pullback/reaction occurred **after that prior break and before the current break**, the current break is `PULLBACK_RESOLUTION`;
- if no such reaction occurred, the current break may be `REACCELERATION`;
- reactions belonging to older legs do not contaminate the current continuation leg.

This removes the arbitrary 24-bar dependency and makes the classification portable across horizons.
