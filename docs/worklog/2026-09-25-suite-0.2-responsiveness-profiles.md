## 5. First decision

### PADRÃO
**KEEP as immutable profile comparator.**

### Naive all-path ANTECIPADO
**REMOVE / DO NOT SHIP.**

Reason:
- excessive event count;
- very low conversion;
- high <=3-bar nonconversion churn;
- most noise is the frozen pullback/retest path.

This does not prove that every nonconverted ARMED event is structurally bad.
It proves that surfacing all ARMED entries as an operator profile is too noisy.

### CONFIRMADO +1 persistence
**KEEP as candidate pending quality discrimination.**

It removes only 6–10% of PADRÃO events and costs one bar.
It is useful only if the rejected cohort is materially worse.
